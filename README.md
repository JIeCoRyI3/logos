# Λόγος в картинках

Тренажёр слов по картинкам к учебнику «Λόγος» (главы Α′–Δ′): уроки в духе Duolingo, повторение по интервалам, кнопка ⓘ с переводом.

Открыть: https://jiecoryi3.github.io/logos/

Это PWA: на iPhone — Safari → «Поделиться» → «На экран „Домой“»; на Android — Chrome → «Установить приложение». После первого открытия работает без интернета, прогресс хранится в телефоне.

Картинки нарисованы заново нейросетью (Qwen Image), иллюстрации из книги не копировались.
